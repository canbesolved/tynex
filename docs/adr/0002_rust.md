# Use Rust

## Context and Problem Statement

`tynex` must be very fast, have a tiny footprint, talk to Wayland and
D-Bus, and later be ported to macOS and Windows. Which language fits?

## Decision Drivers

- Native speed, small binary, low RAM.
- Memory safety in a long-running daemon.
- Mature Wayland, D-Bus and 2D drawing libraries.
- Cross-compilation to macOS and Windows.

## Considered Options

- Rust
- Zig
- C

## Decision Outcome

Chosen option: "Rust", because it matches C and Zig on speed and size
while giving memory safety and the most complete library set
(`wayland-client`, `dbus`, `tiny-skia`).

### Consequences

- Good, because a stub release binary is about 280 KB.
- Good, because the same crate compiles for all three systems.
- Bad, because Rust was not installed and compile times are longer
  than C.

## Pros and Cons of the Options

### Zig

- Good, because it was already installed and has tiny binaries.
- Bad, because Wayland and D-Bus need C bindings and more glue code.

### C

- Good, because it has the smallest possible footprint.
- Bad, because memory bugs in a resident daemon are a real risk.
